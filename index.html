Тренажёр: Иррациональные неравенства

Тип 1. Корень меньше отрицательного числа

Теоретический шаблон: \(\sqrt{f(x)} < a\), где \(a < 0\)

Корень всегда неотрицателен (\(\ge 0\)). Он не может быть меньше отрицательного числа.

Ответ: решений нет (\(x \in \emptyset\)).

Задание 1
\(\sqrt{3x - 2} < -2\)
Ответ: \(\emptyset\)

Тип 2. Корень меньше положительного числа

Теоретический шаблон: \(\sqrt{f(x)} < a\) (или \(\le a\)), где \(a > 0\)

Обе части неотрицательны, возводим в квадрат. Обязательно учитываем ОДЗ:

\[ \begin{cases} f(x) \ge 0 \\ f(x) < a^2 \end{cases} \]

Задание 2
\(\sqrt{x - 2} < 5\)
Ответ: \(x \in [2; 27)\)
Задание 3
\(\sqrt{3 - 2x} \le 7\)
Ответ: \(x \in [-23; 1,5]\)

Тип 3. Корень больше (или \(\ge\)) числа

Теоретический шаблон: \(\sqrt{f(x)} > a\) (или \(\ge a\))

Смотрим на знак \(a\):

  • Если \(a < 0\): корень всегда больше отрицательного числа, если существует. Решение — ОДЗ: \(f(x) \ge 0\).
  • Если \(a \ge 0\): возводим в квадрат, ОДЗ выполняется автоматически: \(f(x) > a^2\) (или \(\ge a^2\)).
Задание 4
\(\sqrt{x + 2} \ge 3\)
Ответ: \(x \in [7; +\infty)\)
Задание 5
\(\sqrt{7 - 3x} > 5\)
Ответ: \(x \in (-\infty; -6)\)
Задание 6
\(\sqrt{2x + 1} > -3\)
Ответ: \(x \in [-0,5; +\infty)\)
Задание 7
\(\sqrt{7 - \frac{x}{2}} \ge -1\)
Ответ: \(x \in (-\infty; 14]\)

Тип 4. Корень меньше выражения с \(x\)

Теоретический шаблон: \(\sqrt{f(x)} < g(x)\) (или \(\le g(x)\))

Корень \(\ge 0\). Чтобы он был меньше \(g(x)\), само \(g(x)\) должно быть строго больше нуля:

\[ \begin{cases} f(x) \ge 0 \\ g(x) > 0 \\ f(x) < g(x)^2 \end{cases} \]

Задание 8
\(\sqrt{x + 8} < x + 2\)
Ответ: \(x \in (1; +\infty)\)
Задание 9
\(\sqrt{x - 2} \le x - 2\)
Ответ: \(x \in \{2\} \cup [3; +\infty)\)

Тип 5. Корень больше выражения с \(x\)

Теоретический шаблон: \(\sqrt{f(x)} > g(x)\) (или \(\ge g(x)\))

Два принципиально разных случая (совокупность):

\[ \left[ \begin{array}{l} \begin{cases} g(x) < 0 \\ f(x) \ge 0 \end{cases} \\ \begin{cases} g(x) \ge 0 \\ f(x) > g(x)^2 \end{cases} \end{array} \right. \]

Задание 10
\(\sqrt{x + 8} > x + 2\)
Ответ: \(x \in [-8; 1)\)
Задание 11
\(\sqrt{x - 2} > x - 2\)
Ответ: \(x \in (2; 3)\)
Задание 12
\(\sqrt{x^2 + 2x} > -3 - x^2\)
Ответ: \(x \in (-\infty; -2] \cup [0; +\infty)\)
Задание 13
\(\sqrt{x^2 + x - 12} > 6 - x\)
Ответ: \(x \in \left(\frac{48}{13}; +\infty\right)\)

Тип 6. Сравнение двух корней

Теоретический шаблон: \(\sqrt{f(x)} < \sqrt{g(x)}\) (или \(\le\))

Оба корня \(\ge 0\), возводим в квадрат. Нужны ОДЗ для обоих:

\[ \begin{cases} f(x) \ge 0 \\ g(x) \ge 0 \\ f(x) < g(x) \end{cases} \]

Задание 14
\(\sqrt{x + 2} > \sqrt{4 - x}\)
Ответ: \(x \in (1; 4]\)
Задание 15
\(\sqrt{2x - 8} \le \sqrt{6x + 13}\)
Ответ: \(x \in [4; +\infty)\)

Тип 7. Корень меньше заведомо неположительного выражения

Теоретический шаблон: \(\sqrt{f(x)} \le g(x)\), где \(g(x) \le 0\)

Корень \(\ge 0\). Чтобы он был меньше или равен выражению \(\le 0\), обе части должны быть равны нулю:

\[ \begin{cases} f(x) \ge 0 \\ g(x) = 0 \\ f(x) = 0 \end{cases} \]

Задание 16
\(\sqrt{x^2 - 3x + 2} \le -1 - |x|\)
Ответ: \(\emptyset\)
Задание 17
\(\sqrt{x^2 - 4x + 13} \le -x^2 + 4x - 1\)
Ответ: \(x \in \{2\}\)

Тип 8. Многоэтажный (вложенный) корень

Теоретический шаблон: \(\sqrt{f(x) + \sqrt{h(x)}} \le a\), где \(a > 0\)

Действуем снаружи внутрь. Возводим в квадрат:

\(f(x) + \sqrt{h(x)} \le a^2 \implies \sqrt{h(x)} \le a^2 - f(x)\)

Далее решаем как Тип 4.

Задание 18
\(\sqrt{2 + \sqrt{x^2 + 2x + 5}} \le 2\)
Ответ: \(x \in \{-1\}\)
